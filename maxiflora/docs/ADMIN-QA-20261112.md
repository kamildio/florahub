# Admin role audit — 12 November 2026

## Fixed

- Production moderation UI now sends stable operation IDs, refreshes the queue after a decision, and supports fresh MFA without discarding the comment.
- Dashboard/navigation show actionable queue counts for company verification, payment reviews, supplier banners, support and board moderation.
- New queue events notify the owner once and open the relevant admin section. Customer replies, bank changes and deletion requests are included. Deletion requests no longer create false company-submission notices.
- Unresolved support cases and payment reviews remain visible even when older than the recent-history window.
- Company list refreshes with platform state; out-of-order responses are ignored. Version changes require explicit review before approval. Successful decisions show confirmation instead of a misleading stale-profile warning.
- Support/banner decisions detect changed versions and retain draft answers until the admin explicitly reviews the latest record.
- Owner-only platform order lookup supports search, status filters, cursor pagination and order history. Contacts and internal fields are not projected. This view cannot alter orders, stock or payments.

## Reproducible validation

Run from `platform`:

- `npm test` — 276 unit tests.
- `npm run test:acceptance` — 20 isolated suites, including the following durable checks.
- `node tests/role-access-api.mjs` — guest, buyer, supplier, owner, content editor, support, moderator and billing role; MFA, permission denial and immediate revocation.
- `node tests/admin-role-journey-api.mjs` — buyer/supplier company submission and approval; deferred MAX; supplier ad moderation/publication and buyer complaint; MAX banner; order readiness and issue; dispute/private replies, stale decisions and resolution; privacy queue.
- `npm run build:node` — TypeScript and standalone production build.

Browser QA used separate synthetic buyer, supplier and owner sessions on loopback. Confirmed ad approval/publication, buyer-visible result, support reply arrival, stale answer preservation, banner approval and supplier quota, company approval confirmation, owner order history. No live order/payment/approval was created for testing.

Existing protected media-upload restrictions remain: quarantined files cannot be approved or published until scanning/processing is available.
