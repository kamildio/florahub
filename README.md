# FloraHub 🌸

Маркетплейс свежих цветов и букетов с доставкой. Продавцы-флористы подключаются к
сервису, получают заказы в кабинет продавца и связываются с клиентами; покупатели
выбирают букеты, оформляют заказ и отслеживают его статус.

> **Стек:** React + TypeScript + Vite + Tailwind CSS (фронтенд) · PHP 8.1 + PDO/MySQL (бэкенд).
> Фронтенд работает автономно на встроенных mock-данных, поэтому его можно
> запустить и посмотреть **без бэкенда и базы**.

## Возможности

- 🛍️ **Каталог** цветов с фильтрами, сортировкой и поиском
- 🏙️ **Несколько городов** (старт — Шымкент, основной), добавляются через админку
- 🌐 **3 языка** интерфейса: Қазақша, Русский, English
- 🌗 **Тёмная и светлая темы** (с учётом системной + переключатель)
- 📱 **Вход по SMS-коду** (телефон → 4-значный код), профиль, текущие заказы и история
- 🚚 **Отслеживание статуса заказа** (таймлайн: принят → собирается → в пути → доставлен)
- 🧑‍💼 **Админ-панель**: каталог, цены, города (активность/основной), заказы, обзор
- 🌷 **Кабинет продавца**: входящие заказы, смена статусов, история продаж
- ♿ Доступность: контраст, фокус-стейты, `prefers-reduced-motion`, клавиатурная навигация

## Структура

```
florahub/
├── frontend/        React + Tailwind SPA (магазин, профиль, админка, кабинет продавца)
├── backend/         PHP REST API (auth по SMS, каталог, заказы, продавец, админ)
└── README.md
```

## Быстрый старт (только фронтенд — рекомендуется для просмотра)

```bash
cd frontend
npm install
npm run dev          # http://localhost:5173
```

Демо-данные уже встроены. Полезные сценарии:

| Что попробовать | Как |
|---|---|
| Вход по SMS | `/login` → любой номер → код **`1234`** |
| История заказов (с примерами) | войдите номером, оканчивающимся на `123 45 67` |
| Админ-панель | `/admin` |
| Кабинет продавца | `/seller` |
| Языки / тема / город | переключатели в шапке |

## Запуск с реальным PHP-бэкендом

**1. База данных** (MySQL 8+):

```bash
mysql -u root -p -e "CREATE DATABASE florahub CHARACTER SET utf8mb4;"
mysql -u root -p florahub < backend/database/schema.sql
mysql -u root -p florahub < backend/database/seed.sql
```

**2. Бэкенд:**

```bash
cd backend
cp config/config.example.php config/config.php   # пропишите доступы к БД
php -S localhost:8000 -t public                   # API на http://localhost:8000/api
```

В dev-режиме SMS-коды не отправляются, а пишутся в `backend/storage/sms.log`.

**3. Фронтенд против API:**

```bash
cd frontend
cp .env.example .env        # VITE_USE_REAL_API=true
npm run dev                 # Vite проксирует /api → localhost:8000
```

Демо-аккаунты из seed: админ `+7 700 000 00 01`, продавец `+7 700 000 00 02`
(код подтверждения смотрите в `storage/sms.log`).

## API (основные эндпоинты)

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/auth/request-code` | отправить SMS-код |
| POST | `/api/auth/verify` | проверить код, выдать токен |
| GET | `/api/cities`, `/api/categories` | справочники |
| GET | `/api/products`, `/api/products/{slug}` | каталог |
| POST/GET | `/api/orders`, `/api/orders/{id}` | заказы (нужен токен) |
| GET/POST | `/api/seller/orders`, `/api/seller/orders/{id}/status` | кабинет продавца |
| GET/POST/PUT/DELETE | `/api/admin/products`, `/api/admin/cities` | админка |

Авторизация — заголовок `Authorization: Bearer <token>`.

## Архитектурные заметки

- **Дизайн-система** — семантические токены цветов через CSS-переменные
  (`frontend/src/index.css`), бренд: лесной зелёный `#15803D` + цветочный розовый `#EC4899`.
- **i18n** — `react-i18next`, словари в `frontend/src/i18n/locales/{ru,kk,en}.json`.
- **Состояние** — `zustand` с персистентностью (тема, город, корзина, авторизация).
- **API-слой** — `frontend/src/lib/api.ts`: один интерфейс, переключается между
  mock и реальным PHP-бэкендом флагом `VITE_USE_REAL_API`.
- Города и каталог в админке/кабинете редактируются в рамках сессии (локальный стейт)
  на mock-данных; при подключённом бэкенде используйте соответствующие эндпоинты.
